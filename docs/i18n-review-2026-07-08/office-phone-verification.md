## 1. 菲律賓 MECO（馬尼拉經濟文化辦事處，台北）

**判定：CONFIRMED**（宣稱成立，現值有誤）

- 電話：外交部官方頁（mofa.gov.tw/OfficesInROC_Content.aspx, os=18）原文：
  > "Phone: 02-2658-8825"
  現值 (02) 2508-1719 錯誤 → 應為 **02-2658-8825**。
- 地址樓層：同一外交部官方頁原文：
  > "114676 臺北市洲子街55&57號2樓" (2F, No. 55,57, Zhouzi St., Neihu Dist., Taipei City 114676)
  現值「10樓」錯誤 → 應為 **2樓**（門牌 洲子街55/57號 本身正確，只有樓層錯）。
  MECO 官網（meco.org.tw）搜尋結果引用同一地址與電話（+886 2 2658 8825, 2F, Chang Hong New Era Building），交叉確認一致。
- 急難救助電話 0966-480-702：查無任何官方或第三方來源提及此號碼（WebSearch 精確比對「"0966-480-702" MECO」零命中，MECO 官方公告、Taiwan OFW 整理頁均未列出）→ **REFUTED as existing**（宣稱「查無佐證」成立）。
  官方/可信來源實際列出的急難號碼是：
  - MECO-ATN 24/7 一般急難熱線（非 OFW 案件）：**02-2658-8550**（Taiwan OFW 整理頁，引用 MECO 官網公告內容）
  - OFW（移工）案件台北專線：**0932-218-057**（Taiwan OFW 整理頁）

**建議最終值**：
```
embassyPhone: "(02) 2658-8825"
embassyAddress: "台北市內湖區洲子街55/57號2樓"
emergencyPhone: "02-2658-8550"   // 24hr 一般急難熱線；原 0966-480-702 查無官方佐證應移除/替換
```

## 3. 泰國貿易經濟辦事處（台北，TTEO）

**判定：CONFIRMED**（電話與樓層宣稱皆成立）

- 電話：TTEO 官方網站中文聯絡頁（tteo.thaiembassy.org/cn/page/contacttteo）原文：
  > 代表號："(886) 2 2775 2211"
  > 泰籍公民服務："(8862) 2775 2211 分機 110-119"
  > 簽證服務："(8862) 2775 2211 分機 103-107" 或 "(8862) 2773 1100"
  外交部官方頁（os=13）亦直接列 "Phone: 02-2775-2211" 為辦事處代表號。
  → 現值 (02) 2773-1100 確實只是**簽證業務分機**，代表號應為 **02-2775-2211**（宣稱成立）。
- 地址樓層：TTEO 官方中文頁原文：
  > "10666臺北市大安區市民大道三段206號1樓"
  現值「20樓」錯誤 → 應為 **1樓**。

**建議最終值**：
```
embassyPhone: "(02) 2775-2211"
embassyAddress: "台北市大安區市民大道三段206號1樓"
```
（原 (02) 2773-1100 可作為「簽證專線」備註保留，但不應作為代表號/緊急聯絡號碼。）

**急難救助電話**：查詢中未見 TTEO 公布獨立 24hr 急難號碼（其官網僅列代表號＋分機），故此欄位維持空缺（不編造）。
